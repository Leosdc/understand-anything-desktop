# Security Policy

## Supported Versions

We only support security updates for the latest stable minor releases. Please upgrade to the latest patch release of the supported version families.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.x | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do **not** report it via public issues or pull requests. 

Instead, please report the vulnerability using **GitHub Private Vulnerability Reporting**:
1. Navigate to the main page of the repository on GitHub.
2. Under the repository name, click **Security**.
3. In the left sidebar, click **Advisories**.
4. Click **Report a vulnerability** to open the advisory form.
5. Provide a detailed description, including steps to reproduce, the impact of the vulnerability, and any potential remediation steps.

Our team will review your report and respond as quickly as possible. Thank you for helping keep this project secure!
